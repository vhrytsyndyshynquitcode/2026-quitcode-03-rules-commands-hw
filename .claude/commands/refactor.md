# Рефакторинг до конвенцій

**Ціль:** $ARGUMENTS
(Якщо в рядку вище немає конкретного файлу — ціль вказана в повідомленні одразу
після назви команди. Немає й там — спитай і зупинись.)

## Кроки

1. **Зафіксуй «до»** і випиши числа, вони потрібні в кінці:
   ```bash
   cd app && npm test && npm run check:rules
   ```
   Із `check:rules` візьми рядки саме для цільового файлу (секція `by file`) і `TOTAL`.
2. Прочитай цільовий файл і його тест (`<файл>.test.ts`), якщо він є. Тест — це
   **специфікація поведінки**: URL, тіло запиту, тексти помилок.
3. Приведи файл до [conventions](../rules/conventions.md) і [architecture](../rules/architecture.md):
   заміни те, що показує `check:rules`, на відповідники з ядра. Нічого не вигадуй —
   публічний API ядра закритий.
4. **Поведінку не змінюй.** Ті самі URL, те саме тіло запиту, ті самі тексти
   помилок і повідомлень журналу. Рефакторинг — не «заодно полагодити»: помітив
   баг — випиши його окремо в підсумок, не чіпаючи.
5. **Зафіксуй «після»** тими самими двома командами й порівняй з «до».
6. Якщо після зміни впав тест — це не «тест застарів»: це змінена поведінка.
   Поверни поведінку, а не правь асерт.

## Acceptance criteria

- [ ] Змінено **лише** цільовий файл (і, за потреби, його прямі імпорти). У
      `git status --short` немає нічого іншого.
- [ ] Асерти в наявних тестах не редаговані: `git diff -- "*.test.ts"` порожній.
- [ ] `cd app && npm test` зелений і **та сама кількість тестів**, що до рефакторингу.
- [ ] `cd app && npm run typecheck` без помилок.
- [ ] `cd app && npm run check:rules`: для цільового файлу **0** порушень; `TOTAL`
      не зріс; `core-untouched` = 0.
- [ ] У підсумку показано числа до → після і перелік замін (що на що).

## Stop

Не чіпай `app/src/core/**`, `app/scripts/**`, `materials/**`
([do-not-touch](../rules/do-not-touch.md)) — навіть якщо так було б зручніше.
Не переписуй сусідні файли «за компанію» і не перегенеровуй `core.lock.json`.
Якщо привести файл до конвенцій **неможливо** без зміни поведінки або без зміни
core — зупинись, покажи, що саме заважає, і чекай рішення людини.
